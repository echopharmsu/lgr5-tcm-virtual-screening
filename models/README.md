## 一、一句话

**本项目未训练、也未微调任何模型。** 全部**对接打分**来自第三方软件 **gnina** 内置的
**卷积神经网络打分模型**（`dense`），本项目的工作是**把它用于 LGR5 这一靶点的虚拟筛选，
并建立可复现的流程与不确定性分析**。

## 三、输入 / 输出

| | 内容 |
| --- | --- |
| **输入** | 受体 PDB（本项目为 `data/receptor_apo_LGR5.pdb`，LGR5 A 链胞外域 3616 重原子）+ 配体（SDF/PDBQT，本项目由 SMILES 经 RDKit ETKDGv3 生成 3D）+ 搜索盒（中心与边长） |
| **输出** | 每个配体最多 `num_modes` 个姿态，每条姿态附 `CNNscore` / `CNNaffinity` / `minimizedAffinity` |
| **本项目的后处理** | 四道过滤（接触 ≥2.5 Å、affinity <0、CNNscore ≥0.60、距位点中心 ≤6 Å）→ 候选清单；另做残基接触、氢键、埋藏比、空腔几何等几何分析 |

## 四、适用范围

**适用**：
- 在**给定受体构象与搜索盒**下，对一批小分子做**同一轮内**的相对排序；
- 判断某个分子是否落在指定位点、姿态是否物理合理（无穿透、有极性锚定）；
- 作为**假说生成**工具，为后续实验（SPR/ITC、突变、细胞实验）提供候选位点与残基清单。

**不适用**：
- **跨轮、跨受体网格比较 CNNscore 的绝对值**（受体原子网格不同会整体平移；
  本项目报告只做同一轮内排序）；
- 预测绝对结合自由能（未做 MM-GBSA / MD 精修）；
- 判定分子的**功能类型**（激动/拮抗/变构调节）—— 这需要实验。

## 五、已知局限

1. **受体刚性**：gnina 默认不采样受体侧链与主链构象。
2. **本靶点无实验配体参照**：RCSB 全库 LGR5 结构 7 个，全部是胞外域，
   HETATM 只有 NAG / 离子 / 水 → **无法做重对接的黄金对照（RMSD 验证）**。
3. **本靶点为浅表面结合**：候选位点埋藏比 0.22–0.35；几何口袋检测在本受体上
   **未找到任何满足类药判据的表面口袋**。
4. **尺寸偏倚**：Spearman(MW vs CNNscore) = −0.68 ~ −0.83 —— 分子越大得分越差，
   大分子皂苷/三萜的负 affinity 主要来自接触面积而非真实亲和力。
   因此本项目**必须做同尺寸子集对照**。
5. **CNNscore 的性质**：它是"该姿态是否像一个真实结合姿态"的可信度，
   **不是**结合强度；它与经验打分（Vina 项）在某些体系上会出现相反排序
   （本项目即出现：CNN 最高的位点与 affinity 最强的位点不是同一个）。
6. **立体化学敏感**：错误的对映体构型会给出不同结论。
   本项目已建**立体化学闸门**（`src/stereo_gate.py`）：对 PubChem 源记录中
   未指定手性的分子做修复/枚举/拦截，而不是让 3D 化静默任选构型。
7. **结果性质**：计算假说生成，**不代表已验证的结合位点或活性分子**。

## 六、本项目的实际创新贡献（附件5 第一条要求说明）

不以"是否自训练模型"作为合规判断，本项目的贡献在于**流程与可靠性建设**：

1. **位点发现不预设**：用全蛋白盲对接 + **姿态质心聚类**（而非 RMSD —— 本配体仅 2 个可旋转键，
   任意两姿态 RMSD 只有 0.3–1.1 Å，无区分度）自主聚出若干候选位点，并逐一排除
   晶体堆积假象位点与蛋白–蛋白界面位点。
2. **立体化学闸门**：发现并修复了"源头记录无立体化学 → 3D 化静默固化任选构型"这一
   会导致结果不可复现的系统性问题，并给出六级策略（auto/fix/enumerate/fail/warn/asis）。
3. **建立不确定性分析**：双名次口径（避免"看似排第 4 其实未通过闸门"的误读）、
   四道几何门禁、尺寸偏倚量化、可信度分级。
4. **可复现性**：全程固定种子；路径与参数集中于 `config.yaml`；
   主运行入口 `predict.py` 一键复现；原始日志完整留存。
5. **否证性结论**：明确指出本靶点上"最负 affinity 的分子多为大分子皂苷（接触面积效应）"、
   "全胞外域无类药表面口袋"、"小分子占位阻断 LGR5–RNF43 组装的假说在结构上不成立"等
   与直觉相反、但对后续实验有指导意义的结果。
