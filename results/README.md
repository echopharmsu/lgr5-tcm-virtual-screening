## 三、读表口径

1. **两个"名次"不可混用**：
   - `CNN名次` = 全部 109 个分子按 CNNscore 降序的名次；
   - `候选表名次` = 「通过闸门者在前、未通过者在后」的两段式排序内的名次。
   同一个分子可能 CNN 名次很靠前、但**判定为 FAIL**。

   > ⚠️ **两段式排序 ≠ 全表按分数排序。** `results.xlsx` / `results.csv` 只保证**每一段内部** CNNscore 降序，
   > 不保证 PASS 段的分数都高于非 PASS 段。实测：全表 CNNscore **最高**的分子是
   > **030 苍术素（0.8949）**，因距位点中心 **6.48 Å > 6 Å** 判 FAIL，落在非 PASS 段首行——
   > 它的分数**高于整个 PASS 段**（PASS 段末位 025 过氧化麦角甾醇 0.6011）。
   > 若要按分数浏览全表，请自行对 CNNscore 列排序。

2. **判定为 PASS 需同时满足四道过滤**：接触 ≥2.5 Å、affinity <0、CNNscore ≥0.60、距位点中心 ≤6 Å。

3. **CNNscore 不可跨轮比较**；本表只做同一轮内排序。

4. **尺寸偏倚**：Spearman(MW vs CNNscore) = −0.68 ~ −0.83，分子越大得分越差。
   跨分子比较须限定分子量档位（本项目另做 MW 200–450 的同尺寸子集对照）。

5. **结果性质**：计算假说生成，**不代表已验证的结合位点或活性分子**。

6. **ADME 列不可与对接分数合并**：末 5 列的 ADME 安全度来自另一个工具（ADMET-AI）的另一套
   量纲，只作平行参考；本表不合成总分、不设权重，判定仍只由四道对接过滤决定。
