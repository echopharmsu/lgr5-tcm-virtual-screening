# LGR5（GPR49）胞外域小分子候选位点论证 —— LRR13–16 凹面

> 本报告与交付包 `results/results.xlsx` / `results.csv`、`results/screen_*.tsv` 同源。
> 主运行入口与复算命令见文末；参数与路径见 `config.yaml`。

## 一、靶点与区域

**LGR5（GPR49）是 GPCR。** 本工作针对其**胞外域**（富含亮氨酸重复序列的 LRR 螺线管）。

文献报道（Peng et al., *Cell Reports* 2013, PMID 23809763）：**抗体结合 LGR5 的 C 端 LRR cap，并可在不依赖 R-spondin 的条件下激活信号**。

> ⇒ 该 C 端区域是一个**被抗体识别、具信号激活功能的功能面**。
> 
> ⚠️ 该文献以**结构域名称**描述这一区域，**未给出残基编号区间**；本报告亦只按结构域名称引用。

> 
> ⚠️ **因此该受体不是游离态（apo）结构**，而是从三元复合物中抽出的 LGR5 构象。

**立体化学审计**

> 全库 109 个分子的立体化学**均由输入记录给出**（各分子未定义手性中心数 **= 0**）。
> 立体化学闸门（`src/stereo_gate.py`）在预处理阶段运行，未检出任何需人工指定的构型。

**四道闸门**（全部同时满足才判 PASS）

| #   | 闸门                  | 依据           |
| --- | ------------------- | ------------ |
| 1   | 最近受体接触 **≥ 2.5 Å**  | 排除与受体原子重叠的姿态 |

| 3   | CNNscore **≥ 0.60** | 打分层          |
| 4   | 距盒心 **≤ 6 Å**       | 落在目标区域       |

## 三、为什么选这个区域（**纯受体几何，不依赖任何对接结果**）

> 本节是整份报告的地基。三条全部是受体坐标上的几何事实，
> **与对接打分、随机种子、配体起跑位置都无关** —— 因此是本工作中最经得起追问的部分。

**1 · 该区域落在凹面内**

对接盒中心距最近受体重原子 **4.04 Å（ASP380）**；最近的 6 个受体重原子所属残基
—— **ASP380 / ASN404 / ARG382 / SER402 / ILE379 / LYS378** —— **全部位于 LRR13–16（残基 353–446）内**。

**2 · 结合面跨越功能面边界**

13 个接触残基中：**12 个位于 LRR13–16**，**1 个（LYS449）位于 C 端功能面一侧**。
⇒ **结合面本身跨越两段边界**，而非仅落在其中一段内部。

**3 · 不占用生理配体界面**

| 比对                   | 界面残基数            | 与 13 个接触残基的重合 |
| -------------------- | ---------------- | ------------- |
| LGR5(A) ↔ RSPO1(M/P) | 36（最近重原子 2.74 Å） | **0**         |
| LGR5(A) ↔ RNF43(E/F) | 19（最近重原子 2.91 Å） | **0**         |

该区域距 **RSPO1 界面 27.57 Å**；**13 个接触残基**与 RSPO1 / RNF43 界面的**重合均为 0**。
⇒ **「小分子占据该位点直接阻断 LGR5–RNF43 组装」这一假说在结构上不成立**
（要影响组装需作用于界面本身；构象传递属本刚性对接无法回答的问题）。

## 四、结果

| 项                 | 值                                                    |
| ----------------- | ---------------------------------------------------- |
| 完成对接的分子           | **109 / 109**                                        |
| 总姿态数              | **981**（109 × 9）                                     |
| 通过四道闸门的分子         | ⚠️ **不作性能指标**（见下）                                    |
| 任一姿态落在盒心 6 Å 内的分子 | **104–106 / 109**（基准口径 4 个种子；交付轮 seed 42 实测 **104**） |
| 接触残基重叠中位数         | **10 / 13**                                          |

### 4.1 ⚠️「通过闸门的分子数」不作性能指标

按 **4 个随机种子**实测（口径：重原子质心 · 第 1 条姿态 · **CNNscore ≥ 0.60 且 距中心 ≤ 6.0 Å**；
另两道闸门「最近接触 ≥ 2.5 Å」「affinity < 0」在本批数据中未被触发，不影响结果）：

| 配体起跑口径            | 4 个种子的通过数         | 范围        |
| ----------------- | ----------------- | --------- |
| **基准**（配体质心平移到盒心） | 19 / 13 / 13 / 19 | **13–19** |
| **无冲突起跑**         | 10 / 19 / 14 / 21 | **10–21** |

**且通过名单本身也不稳定**：四个种子里**都**通过的分子，两种口径各只有 **4 个**（Jaccard **0.12**）。
⇒ **单次运行给出的清单，本质是一次抽样。**

**⇒ 本报告的主张落在「该凹面被全库分子广泛占据」这个定性事实上，不落在通过计数上。**

### 4.2 ★ 唯一稳定的一条（分子级）

> **在 2 种配体起跑口径 × 4 个随机种子共 8 次运行中，全部通过四道闸门的分子只有 2 个：
> 001（刺芒柄花素）与 013（大豆苷元）。**

这条不依赖任何单次运行、不依赖起跑口径，可逐次复算。

## 七、空腔几何

口径：**0.5 Å 网格**，dmin = 网格点到最近受体重原子的距离；
**溶剂过滤** = 该点 8 Å 内受体原子数 ≥ 20。

| 指标                    | 值                                          |
| --------------------- | ------------------------------------------ |
| 盒心 3 Å 内最大自由球半径       | **5.12 Å**                                 |
| 全胞外域同口径最大自由球半径        | **6.84 Å**（距盒心 64 Å 处）                     |
| 该点包埋度（64 射线）          | **0.36**                                   |
| 衬里残基                  | ASP358 / ASP380 / LYS378 / THR334 / VAL356 |
| 埋藏比（8 Å ÷ 12 Å 邻域原子数） | **0.30**                                   |

> **怎么读**：自由球半径小 = 该处空间较**紧**。配合较高的接触密度与 6 个极性接触，
> 说明配体是**填满了一个较窄的凹槽**，而不是松散地"搭"在表面。
> 
> ⚠️ **与 `pocket_scan.py` 的已知缺陷划清界限**：本项目另有一个口袋检测脚本
> `src/pocket_scan.py`，其体积计算**不排除体相溶剂**（泛洪漏进溶剂 ⇒ 体积虚高），
> 导致其「表面口袋候选」列表被构造性筛空。**本节的 5.12 Å 用的是上述 0.5 Å 网格 + 溶剂过滤口径，
> 不受该缺陷影响**；但**凡引用 `pocket_scan.py` 输出（含「类药表面口袋 0 个」）的结论均不可用**。

## 八、局限

1. **通过计数不作定量结论引用。** 已用 **4 个随机种子 × 2 种配体起跑口径（共 8 次运行）**复现：
   通过闸门的分子数在 **13–19**（基准起跑口径）/ **10–21**（无冲突起跑口径）之间；
   **四种子共同通过者各仅 4 个（Jaccard 0.12）**；**跨 8 次运行稳定通过的只有 001 / 013**。
   ⇒ **故四道闸门的通过计数不作定量结论引用。**

2. **配体起跑位置。** 预处理将每个配体的质心平移到盒心，导致配体起跑时原子与受体穿插
   （实测 **108/109** 个分子起跑最近接触 < 2.5 Å）。以**无冲突位置**起跑的对照中，
   通过数同样在 **10–21** 间摆动，**但该凹面被占据的情况不变**（任一姿态口径 **104–106/109**；
   13 个接触残基重叠中位 **10/13**；基准通过的 19 个分子在无冲突起跑下**全部**保持 ≥5/13 重叠）。

3. **受体构象取自三元复合物，非游离态。** PDB 4KNG 是 LGR5–RSPO1–RNF43 三元复合物；
   本工作仅保留 LGR5 链后使用。该区域被文献称为「铰链区」——**其构象是否随结合状态变化，本工作未作评估**。
   受体按刚性处理，未做柔性对接或 MD。

4. **浅表面结合。** 埋藏比 **0.30**、自由球半径 **5.12 Å**（明显小于全胞外域最大 6.84 Å）。

5. **受体为刚性、仅胞外域**（不含 7TM 与胞内区）；胞外域 **484–536 共 53 个残基未建模**。

6. **无共晶小分子可对照。** LGR5 与 LGR4 均无任何实验解析的小分子配体
   （RCSB 全库：LGR5 实验结构 7 个，全为胞外域，HETATM 只有 NAG / 离子 / 水）
   ⇒ **无法做重对接 RMSD 的黄金对照**；本项目所有位点均无实验参照。

7. **打分受分子尺寸影响**，且两个指标方向相反（见 §5.1）；跨分子比较须限定尺寸档位。

8. **立体化学**：全库 109 个分子的立体化学均由输入记录给出（未定义手性中心数 = 0）。

9. **CNNscore 不可跨轮或跨受体网格比较**（网格不同会整体平移）；本报告只用同轮内排序。

10. **结论性质：计算假说生成，未经实验验证。**

## 九、后续计算工作建议（纯计算）

| #   | 建议                                         | 目的                      | 成本  |
| --- | ------------------------------------------ | ----------------------- | --- |
| 1   | **MD 模拟**（3 × 100 ns，位点–配体复合物）             | 检验姿态在动力学下是否稳定、主链氢键是否保持  | 高   |
| 2   | **MM-GBSA / MM-PBSA 重打分**                  | 修正对接打分的近似，降低尺寸偏倚        | 中   |

| 4   | **计算丙氨酸扫描**                                | 找出结合关键残基 → 给突变实验提供清单    | 低–中 |
| 5   | **LGR4 / LGR6 同源结构对照对接**                   | 选择性假说                   | 中   |
| 6   | **共折叠验证**（AF3 / Boltz 类）                   | 独立方法交叉验证结合模式            | 中   |
| 7   | **补齐溶剂排除后的口袋检测**（修 `pocket_scan.py` 后重算）   | 给「该位点在全胞外域中的几何排名」一个可信数字 | 低   |
